FAQ

Pertanyaan yang Sering Diajukan

Berapa lama pengerjaan map custom?
Tergantung kompleksitas. Map sederhana selesai dalam 3–7 hari, map medium 1–2 minggu, dan project besar bisa 3–4 minggu. Timeline pasti disepakati sebelum pembayaran.
Apakah map include script?
Ya. Semua map kami include scripting dasar (leaderstats, save data, dll). Sistem kompleks seperti pet simulator atau tycoon advanced dapat dibahas sesuai kebutuhan dan mempengaruhi estimasi harga.
Bagaimana cara serah terima map-nya?
Map dibangun di Roblox Studio dan diserahkan via Team Create / di-publish ke game milik kamu, lengkap dengan file .rbxl jika diperlukan. Kami pandu step-by-step sampai map berjalan.
Apakah menerima customer dari luar Indonesia?
Tentu! Kami menerima pembayaran internasional via PayPal, Wise, atau USDT. Silakan order seperti biasa dan sebutkan negara kamu di detail request.
Apakah aman dari sisi aturan Roblox?
Kami mengerjakan map sebagai jasa jasa/pembuatan konten — model bisnis yang umum di komunitas developer Roblox. Kami tidak menjual item in-game atau Robux, dan menyarankan transaksi dilakukan dengan transparan. Kamu tetap bertanggung jawab atas kepatuhan penggunaan map pada pengalaman kamu terhadap Terms of Service Roblox.
Bagaimana sistem revisi?
Setiap paket custom termasuk revisi minor gratis (warna, penempatan objek, penyesuaian kecil). Revisi besar di luar scope awal akan dihitung tambahan dengan persetujuan kamu dulu.
